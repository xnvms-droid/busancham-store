# 후원주점 서빙 시스템

종이 주문서·수기 계산 방식을 대체하기 위한 웹 기반 주문·서빙·결제 관리 시스템입니다.
노트북 1대를 포스(현황판)로, 서빙 인원 각자의 휴대전화를 주문 단말기로 사용하며, 모든 기록은 구글 시트에 자동 저장됩니다.

## 1. 화면 구성

| 화면 | 사용 기기 | 주요 기능 |
|---|---|---|
| 포스 현황판 (`#pos`) | 노트북 | 전체 테이블 현황(인원·수저세팅·주문액·미결제·경과시간), 미서빙 주문 목록 및 메뉴별 미서빙 집계, 테이블별 주문 입력·결제·이동·정리, 메뉴 품절 처리 |
| 서빙 주문 (`#serve`) | 휴대전화 | 테이블 선택 → 인원·수저세팅 입력, 메뉴 선택 후 주문 전송, 서빙완료 처리, 현금 결제(거스름돈 계산) |
| 정산 (`#settle`) | 노트북 | 총 주문액, 수납액(현금·계좌이체), 미수금, 메뉴별 판매 수량·금액, 테이블(팀)별 내역, 인쇄 |

화면은 3~4초 간격으로 자동 갱신되어, 휴대전화에서 넣은 주문이 포스 화면에 곧바로 표시됩니다.

## 2. 파일 구성

```
index.html            화면 전체 (GitHub Pages로 게시)
config.js             서버 주소(API_URL) 설정 파일
apps-script/Code.gs   구글 시트에 붙여넣는 서버 코드
demo/gas-mock.js      체험판 전용 파일 (index.html?demo=1)
```

## 3. 설치 절차

### 3-1. 구글 시트 및 서버(Apps Script) 준비

1. 「후원주점 서빙 시스템」 폴더의 구글 시트 **후원주점_서빙데이터** 를 엽니다. (새 구글 시트를 만들어도 무방합니다)
2. 상단 메뉴 **[확장 프로그램] > [Apps Script]** 를 선택합니다.
3. 편집기의 기본 코드를 모두 지우고 `apps-script/Code.gs` 파일 내용 전체를 붙여넣은 뒤 저장(Ctrl+S)합니다.
4. 상단 함수 선택 목록에서 **setup** 을 선택하고 **[실행]** 을 누릅니다. 최초 1회 권한 승인 창이 나타나면 본인 계정으로 승인합니다.
   - "Google에서 확인하지 않은 앱" 안내가 나오면 [고급] > [(프로젝트명)(으)로 이동]을 눌러 진행합니다.
5. **[배포] > [새 배포]** 를 누르고 유형 톱니바퀴에서 **웹 앱** 을 선택한 뒤 아래와 같이 설정하고 [배포]를 누릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둡니다.

> **유의** 조직(Google Workspace) 계정에서는 관리자 정책에 따라 액세스 권한에 「모든 사용자」 항목이 표시되지 않을 수 있습니다. 이 경우 서빙 인원의 휴대전화에서 접속이 되지 않으므로, 개인 Gmail 계정의 구글 드라이브에 시트를 만들어 3-1 절차를 진행하시기 바랍니다.

### 3-2. GitHub Pages 게시

1. GitHub에서 새 저장소(예: `hujeom-pos`)를 **Public** 으로 생성합니다. (무료 요금제는 공개 저장소에서만 Pages를 사용할 수 있습니다)
2. 저장소 화면의 **[Add file] > [Upload files]** 에서 `index.html`, `config.js`, `README.md`, `apps-script` 폴더, `demo` 폴더를 끌어다 올리고 [Commit changes]를 누릅니다.
3. **[Settings] > [Pages]** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 지정하고 [Save]를 누릅니다.
4. 1~2분 후 표시되는 주소(`https://아이디.github.io/hujeom-pos/`)가 접속 주소입니다.

### 3-3. 서버 주소 연결

1. 저장소의 `config.js` 를 열고 연필(편집) 아이콘을 누릅니다.
2. `API_URL: ''` 의 따옴표 안에 3-1에서 복사한 웹 앱 URL을 붙여넣고 [Commit changes]를 누릅니다.
3. 1~2분 후 접속 주소로 들어가면 「접속 비밀번호」를 묻습니다. 구글 시트 「설정」 탭의 비밀번호(초기값 1234)를 입력합니다.

> 접속 주소는 공개되어 있으므로, 행사 전 「설정」 탭의 **접속비밀번호를 반드시 변경**하시기 바랍니다. 비밀번호는 각 기기에 한 번만 입력하면 저장됩니다.

## 4. 행사 전 준비

- **메뉴·가격**: 구글 시트 「메뉴」 탭에서 분류·메뉴명·가격을 수정합니다. 상태는 `판매 / 품절 / 숨김` 중 선택합니다. 현재 입력된 메뉴는 예시입니다.
- **행사명·테이블 수**: 「설정」 탭에서 수정합니다.
- **리허설**: 리허설로 생긴 주문·결제 기록은 구글 시트 상단 메뉴 **[후원주점] > [행사 데이터 초기화]** 로 삭제합니다. (메뉴·설정은 유지)
- **기기 설정**: 서빙 인원은 휴대전화에서 접속 주소를 연 뒤 「홈 화면에 추가」를 해 두면 앱처럼 사용할 수 있습니다. 상단 [이름 설정]에 이름을 넣으면 주문·결제 기록에 입력자가 함께 저장됩니다.
- **포스 노트북**: 화면 꺼짐·절전 모드를 해제하고 충전기를 연결해 둡니다.

## 5. 운영 요령

1. **손님 착석** — 서빙 인원이 휴대전화에서 테이블 번호를 누르고 인원(＋/－)과 수저세팅 여부를 입력합니다. 첫 주문을 넣으면 자동으로 착석 처리됩니다.
2. **주문** — [주문 입력] 탭에서 메뉴를 눌러 수량을 담고 [주문 넣기] → 확인 창에서 다시 확인 후 전송합니다. 요청사항(예: 덜 맵게)을 함께 적을 수 있습니다.
3. **조리·서빙** — 포스 화면 오른쪽 「미서빙 주문」에 테이블 번호와 메뉴가 주문 순서대로 쌓이며, 상단에 메뉴별 수량이 합산 표시됩니다. 서빙 후 [서빙완료]를 누릅니다. (15분 이상 지연된 주문은 붉게 표시)
4. **결제** — 테이블 상세의 [현금 결제]를 누르고 받은 돈을 입력하면 거스름돈이 계산됩니다. 나눠 내기는 결제 금액을 수정해 여러 번 처리합니다. 잘못 처리한 결제는 음수 금액(예: -10000)으로 정정합니다.
5. **퇴장** — [테이블 정리(퇴장)]를 누르면 빈자리로 바뀌고 기록은 「이용내역」 탭에 보존됩니다. 미결제·미서빙이 남아 있으면 경고가 표시됩니다.
6. **자리 이동** — [테이블 이동]으로 빈 테이블을 선택하면 주문·결제 내역이 함께 옮겨집니다.
7. **품절** — 포스 화면 [메뉴 품절관리]에서 품절 처리하면 모든 휴대전화에서 해당 메뉴가 선택 불가로 바뀝니다.
8. **정산** — [정산] 화면에서 메뉴별 판매, 현금·이체 수납액, 미수금을 확인하고 [인쇄]로 출력합니다. 원자료는 구글 시트 「주문」「결제」「이용내역」 탭에 그대로 남습니다.

## 6. 체험판

접속 주소 뒤에 `?demo=1` 을 붙이면(예: `https://아이디.github.io/hujeom-pos/?demo=1`) 서버 연결 없이 모든 화면을 시험해 볼 수 있습니다. 체험판 데이터는 해당 브라우저에만 저장되며, 같은 브라우저의 탭 두 개에 포스·서빙 화면을 각각 열면 연동 상황도 확인할 수 있습니다.

## 7. 참고 사항

- 서버 코드(Code.gs)를 수정한 경우 **[배포] > [배포 관리] > 연필 아이콘 > 버전: 새 버전** 으로 다시 배포해야 반영됩니다. (URL은 바뀌지 않습니다)
- 동시에 여러 휴대전화에서 주문이 들어와도 서버에서 순서대로 처리하며, 통신 불량으로 같은 주문을 두 번 전송해도 한 번만 접수됩니다.
- 구글 시트에서 메뉴·설정을 직접 수정하면 수 초 이내에 모든 화면에 반영됩니다. 다만 「주문」「결제」 탭의 기록은 시스템이 관리하므로 행사 중에는 직접 수정하지 않는 것을 권장합니다.
- 화면 갱신 간격은 `config.js` 의 `POLL_MS` 값(밀리초)으로 조정할 수 있습니다.
